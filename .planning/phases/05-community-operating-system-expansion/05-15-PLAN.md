# 05-15 PLAN - Global Text Overflow Hardening

## Objective

Reduce text overlap across the application by enforcing safer wrapping and min-width behavior in shared layout primitives, PrimeReact controls, and grid columns.

## Scope

- Add `min-width: 0` protection to grid columns and shared metadata rows.
- Harden wrapping for card titles, card copy, badges, pills, filter chips, button labels, dropdown labels, and datatable cells.
- Keep the fix global so remaining screens inherit safer text behavior without local patching.

## Acceptance Criteria

- Long Spanish copy no longer overlaps cards or squeezes adjacent controls as easily.
- PrimeReact buttons, select buttons, dropdown labels, and datatable cells wrap instead of forcing overflow.
- Frontend build passes in Docker and docs/state remain aligned.

## Verification

- `docker exec infra-civic-web-dev-1 sh -lc "cd /workspace && npm --workspace apps/web-react run build"`
- `npm run agent:context:check`
- `npm run backlog:current:check`
