# 05-12 PLAN - Cross-App Stat Grid Hardening

## Objective

Finish the cross-application refactor of fragile community summary blocks so Spanish copy, longer role names, and narrower layouts no longer break card rhythm or text legibility.

## Scope

- Extend `CivicStatCard` usage into remaining high-risk summary surfaces.
- Remove hardcoded signal-detail summary blocks and replace them with shared stat primitives.
- Harden global wrapping behavior for shared badges and buttons.
- Localize remaining signal-detail strings tied to protocol, evidence, and lifecycle actions.

## Acceptance Criteria

- Settings, Communities, Dashboard, CommunityFeed, and SignalDetail use resilient stat-grid behavior for summary content.
- Long ES labels do not split into broken vertical fragments inside summary cards.
- Shared badges/buttons wrap safely instead of overflowing or overlapping cards.
- Frontend build passes in Docker and UX evidence is captured with the Playwright wrapper.
