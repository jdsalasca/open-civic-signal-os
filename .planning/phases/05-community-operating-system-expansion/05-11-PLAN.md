# 05-11 Plan - Cross-App Stat Cards and Responsive Summary Grids

## Objective

Replace fragile one-off summary metrics with a reusable cross-application stat-card primitive and shared responsive layout behavior.

## Scope

- add reusable `CivicStatCard`
- migrate summary metric surfaces in `Settings`, `Dashboard`, and `CommunityFeed`
- standardize responsive grid sizing for those summary surfaces
- validate the UI from the Docker runtime with screenshot evidence

## Notes
