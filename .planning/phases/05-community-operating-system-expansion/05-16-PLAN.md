# 05-16 PLAN - Cross-App Light Theme and Responsive Consistency Hardening

## Objective

Eliminate remaining text overlap, cramped stat cards, and light-theme contrast regressions by hardening shared layout primitives and updating the highest-risk community workflows to use them.

## Scope

- Remove remaining hardcoded light-theme-breaking surfaces from shared form controls.
- Broaden shared stat-card/grid tokens so Spanish copy and medium-length values fit without card blow-up.
- Normalize mobile navigation, topbar, dropdown, and select-button wrapping behavior.
- Reduce Settings identity density and replace fragile summary blocks with calmer shared surfaces.
- Move report summary and signal detail summary blocks onto the shared stat-card system.

## Acceptance Criteria

- Light theme no longer shows dark text over dark control backgrounds in shared dropdown/select surfaces.
- Mobile nav, topbar community selector, and shared buttons wrap safely instead of clipping or forcing single-word truncation.
- Settings, CommunityFeed, ReportSignal, and SignalDetail inherit the same responsive stat-card behavior without local metric-card drift.
- Frontend build passes in Docker and state/changelog remain aligned.
