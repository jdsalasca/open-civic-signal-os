# 05-10 Plan - Civic Profile Recognition Surface

## Objective

Strengthen the community identity experience so profile settings feel inhabited and useful instead of a plain admin form.

## Scope

- persist one backend-validated avatar preset per user
- expose backend-owned milestone achievements in profile payloads
- convert affiliations input into tag-based editing with community-derived suggestions
- improve settings identity layout so mini-stat cards and profile recognition surfaces remain legible in ES and mobile
- seed the pending follow-up backlog item for broader cross-app identity recognition

## Validation

- `mvn -q -Dtest=UserProfileVisibilityIT test`
- `docker exec infra-civic-web-dev-1 sh -lc "cd /workspace && npm --workspace apps/web-react run build"`
- `npm run agent:context:check`
- `npm run backlog:current:check`
- `npm run agent:adr:check`
- `npm run agent:ux:pw -- open http://localhost:5173/settings --headed`
- `npm run agent:ux:pw -- snapshot`
- `npm run agent:ux:pw -- screenshot output/playwright/profile-recognition-settings.png`

## Notes

- Backend owns achievement progress and avatar preset validation.
- Frontend owns only rendering, tag interaction, and visual preset gallery presentation.
