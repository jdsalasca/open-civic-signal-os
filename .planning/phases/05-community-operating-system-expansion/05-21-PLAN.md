# Phase 5.21 Plan - Structured Proposal Deliberation

## Objective

Implement `story:OCS-P1-041` so community proposals support backend-owned structured deliberation with typed arguments, evidence, and moderation that preserves proposal context.

## Scope

- backend deliberation domain + migration
- proposal deliberation endpoints and permission reuse
- frontend deliberation workflow inside proposal detail
- OpenAPI + ADR + backlog/state updates
- backend integration test + Playwright flow update

## Acceptance Criteria

- proposals expose typed deliberation entries: `PRO`, `CON`, `QUESTION`, `EVIDENCE`
- evidence entries require one supporting public link
- deliberation counters remain backend-owned
- moderators can hide or restore one entry without deleting proposal context
- proposal detail visually separates argument types
