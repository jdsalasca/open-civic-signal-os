# 05-17 PLAN - Cross-App Typography and Surface Standardization

## Objective

Remove remaining visual drift in list surfaces, section headers, metadata rows, and card notes so the app uses one coherent typographic and card language across community workflows.

## Scope

- Introduce shared typography helpers for eyebrows, section titles, list titles, list copy, and metadata values.
- Reuse shared surface-note styling instead of repeating local rounded-border note blocks.
- Apply the standard to high-traffic community surfaces: blog, threads, signal table, digest, notification sidebar, and shared page/meta primitives.

## Acceptance Criteria

- Equivalent content types use the same visual hierarchy across blog, threads, dashboards, and sidebars.
- Long labels and titles wrap consistently without truncation-heavy drift.
- Shared note cards and list rows no longer rely on one-off border/background combinations.
- Frontend build passes in Docker and planning state/changelog remain aligned.

- `npm run agent:context:check`
