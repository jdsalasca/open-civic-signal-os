# 05-18 PLAN - Responsive Usability Hardening Across Community Hubs

## Objective

Improve readability and responsive behavior in the remaining dense community surfaces so text no longer fractures under narrower widths or mixed-content layouts.

## Scope

- Standardize metric-card composition for dashboard metrics.
- Apply the shared typography/surface system to Communities hub, CommunityMap, and Moderation.
- Reduce rigid labels and strengthen list-card readability in tree, hotspot, membership, and moderation queue surfaces.

## Acceptance Criteria

- Communities, CommunityMap, Moderation, and MetricsGrid use the same typography and surface system as the rest of the app.
- Long titles and metadata wrap cleanly on smaller widths instead of clipping or forcing awkward density.
- Build and backlog/context checks pass; screenshot evidence is produced.

## Verification

- `docker exec infra-civic-web-dev-1 sh -lc "cd /workspace && npm --workspace apps/web-react run build"`
- `npm run agent:context:check`
- `npm run backlog:current:check`
- `npm run agent:ux:pw -- screenshot output/playwright/community-hubs-responsive-pass.png`
