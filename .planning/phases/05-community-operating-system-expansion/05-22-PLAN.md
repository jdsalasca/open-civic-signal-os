# Phase 5.22 Plan - Community Project Boards

## Objective

Implement `story:OCS-P1-043` so communities can move approved work into visible execution boards with backend-owned tasks, statuses, owners, and task notes.

## Scope

- backend project-board domain + migration
- permission scope for board/task execution control
- community project board endpoints
- frontend kanban workflow for boards, tasks, status movement, and notes
- OpenAPI + ADR + backlog/state updates
- backend integration test + Playwright flow

## Acceptance Criteria

- boards can optionally link back to one structured proposal
- tasks move deterministically across `TODO`, `IN_PROGRESS`, and `DONE`
- tasks support assignee, due date, and execution notes
- board and task visibility stays community-scoped and backend-owned
- frontend shows visible execution progress instead of proposal-only intent
