# Phase 5.23 Plan - Governance Library

## Objective

Implement `story:OCS-P1-046` so communities can search, read, and version governance records through one backend-owned library instead of scattered references.

## Scope

- backend governance document domain + migration
- permission scope for governance publishing and versioning
- governance library endpoints with search and visibility rules
- frontend governance library workflow for search, detail, creation, and version publishing
- OpenAPI + ADR + backlog/state updates
- backend integration test + Playwright discovery flow

## Acceptance Criteria

- governance documents are searchable by type, audience, and community text query
- current version and version history remain visible in one detail workflow
- visibility rules are explicit and backend-owned
- authorized roles can publish new governance records and version updates
- communities can navigate to governance records from the main collaboration surfaces
