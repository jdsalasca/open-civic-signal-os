# 05-14 PLAN - Community Home and Dashboard Density Pass

## Objective

Reduce visual overload in the dashboard and community-home surfaces by grouping secondary actions, improving action-bar wrapping, and standardizing list-card presentation across the highest-traffic community views.

## Scope

- Normalize action-bar behavior for long-button clusters.
- Reduce flat CTA rows in dashboard hero, secondary actions, quickstart, and priority strips.
- Improve community-home header hierarchy and overview actions.
- Standardize feed list-card surfaces for official updates, hot threads, and top signals.

## Acceptance Criteria

- Dashboard secondary actions and quickstart areas no longer feel like unstructured button piles.
- Community home header and overview communicate freshness + next actions without crowded controls.
- Repeated list cards inside the community home use one shared surface style.
- Frontend build passes in Docker and supporting docs/state are updated.
